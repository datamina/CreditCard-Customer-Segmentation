## Objective
Finding the most useful customer segmentation to improve the marketing strategy of the company.

## Methods Used
Exploratory Descriptive Analysis
Data Visualization
Clustering
Anomaly detection

## Technologies
Python
Pandas, jupyter

## Project Description
### Data & Methodology
8500 customers and their activity over a 6-month period.

### Tools & Techniques:
Data Processing: pandas
Visualization: matplotlib
Clustering: K-means, t-SNE, Hierarchichal clustering, elbow method, silhouette method

### Constraints
2-day challenge

## Key Findings
We identified three customer groups:
1. Frequent purchasers with installments
2. "Cash in Advance" users
3. Casual, less active users: representing the majority of the customer base, with lower financial risk and high market potential, making them an ideal target for a marketing campaign.

We applied three clustering methods, exploring different perspectives:
  - Some approaches suggested two customer groups instead of three.
  - However, validation confirmed the three-group segmentation.
